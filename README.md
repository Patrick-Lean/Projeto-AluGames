# Projeto AluGames

Este projeto serve como um treinamento sobre lógica de programação. A parte central do projeto foi a implementação do condicional em um projeto mais visual. A parte de recuperar informações de tags foi considerado como objetivo secundário.

## Qual foi a entrada? O que se tinha de início?

Este projeto contava com todos os aparatos visuais, mas a parte da implementação lógica foi desenvolvida dês do inicio.

## O que foi feito?

A partir do arquivo HTML foi observado que a função alterarStatus(id) era a parte principal da lógica a ser desenvolvida em JavaScript. Ao notar a função, foi desenvolvido uma lógica de alterar a imagem e o botão conforme o status atual. Se o jogo está disponível, a imagem deve estar mais clara e o botão de alugar deve estar disponível. Entretanto, se o jogo não está disponível, a imagem deve escurecer levemente e apresentar o botão de devolver. Logo, ao clicar no botão, deve alternar entre os estados de alugado e disponível.
